# GitHub Brand Animations

Generated sprite animation experiments inspired by GitHub's Octodex mascots.

## Contents

- `previews/videos/` — MP4 previews of the generated animations.
- `assets/spritesheets/` — editable right/left spritesheets for SpriteForge-style cleanup.
- `previews/contact-sheets/` — quick visual inspection sheets.
- `tools/` — local helper scripts used to clean backgrounds, mirror frames, and render previews.

## Featured characters

- Mona / classic Octocat
- Mona the Rivetertocat
- Robotocat
- Dinotocat
- Securitocat
- OctoLiberty
- Jetpacktocat
- Codercat
- Pythocat
- Octobiwan
- Labtocat
